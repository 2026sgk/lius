# 银行流水如何查询

银行流水是指个人或企业银行账户在一定时期内的交易记录，包括存取款、转账、消费和收入等明细。查询银行流水可以帮助用户了解账户资金变动情况。

要查询银行流水，用户通常可以通过银行官方渠道进行，例如银行柜台、网上银行、手机银行 APP 或自助终端等方式。在进行查询前，可能需要提供账户信息和身份验证。

银行流水涉及个人隐私和账户安全，用户在查询和保存时需注意保护相关敏感信息，避免泄露造成不必要的风险。

总的来说，通过官方渠道查询银行流水是合法且安全的操作，可以帮助用户进行账务管理和资金核对。
